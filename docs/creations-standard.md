# תקן "יצירות": כל אפליקציה מפיקה כתבות ויצירות מהידע שלה

ענת, 03.11.2026: "כל אפליקציה צריכה שיהיה לך דף עם כתבות שהיא יכולה להפיק מנושאים שונים שעולים מהידע, הבנה ויישום. היצירות של האפליקציה."
כל נושא הוא **חדר**. בכל חדר יש כמה יצירות בעיצובים שונים, וכל יצירה ראויה לעמוד בפני עצמה במיצג.
כל יצירה עולה לחדר משלה ב-TAARUCHA, ויורדת להדפסה בגודל A4.

## הרכיב
```html
<script src="https://anat1969.github.io/AppOfApp-GH/creations.js"
        onerror="var s=document.createElement('script');s.src='https://appofapp-gh.vercel.app/creations.js';document.head.appendChild(s)"></script>
<app-creations src="./creations.json" heading="מה האפליקציה יוצרת"></app-creations>
```
- הקוד נמצא ב-`public/creations.js` בריפו הזה, בלי תלויות.
- הוא נטען קודם מ-GitHub Pages, ואם הטעינה נכשלת, מ-Vercel.
- ב-React: `<app-creations src="./creations.json" />` בתוך דף, וטעינת הסקריפט ב-`index.html`.
- הרכיב מציג:
  - כותרת ושורת "למה".
  - סינון לפי שלב: הכול, ידע, הבנה או יישום.
  - חדר לכל נושא.
  - שלושה כפתורים לכל חדר: הדפסת החדר A4, העלאה לחדר בתערוכה, כניסה לחדר.
  - לכל יצירה: לחיצה מגדילה אותה, וכפתור "הדפסה A4".
- כל יצירה היא גיליון בפרופורציה של A4. הוא בנוי ביחידות `cqw`, ולכן נראה אותו דבר במסך, בהדפסה ובקובץ PNG.

## תשעת העיצובים (`style`)
| style | שם | שדות |
|---|---|---|
| `poster` | טקסט על תמונה | title, text, image, pos |
| `gradient` | שדה צבע (גרדיינט מצבעי ה-DNA) | title, text |
| `veil` | שקיפות: זכוכית חלבית על תמונה | title, text, image |
| `insight` | תובנה: שורה גדולה, הסבר עם פס מרקר | title, text |
| `quote` | ציטוט מוגדל | quote, who, cite |
| `haiku` | הייקו בשלוש שורות מדורגות, וחותם | lines[3], text |
| `post` | פוסט מוכן לרשת | title, text (שורות ב-\n), image, tags[] |
| `fromto` | פרשנות ממה למה | title, from, to, fromLabel, toLabel, text |
| `essay` | מאמר בשתי עמודות | title, text (פתיח), image, body[] |

**שדות לכל יצירה:**
- `id`, `style`.
- `kicker`: מופיע בתחתית היצירה.
- `credit`: קרדיט לתמונה.
- `png`: נכתב אוטומטית בייצוא.

**סימון בטקסט:** `**מודגש**` לבולד, ו-`==מרקר==` להדגשה במרקר צהוב.

## creations.json
```json
{
  "app": { "id": "amirot", "name": "אמירות", "url": "https://amirot-gh.vercel.app", "repo": "Anat1969/Amirot-GH",
           "palette": { "a": "#1f3a68", "b": "#a3261e", "c": "#b8700f", "s": "#1d7a4f", "accent": "#1d7a4f", "paper": "#fff" } },
  "topics": [
    { "id": "haste", "zone": "הבנה", "title": "למהר או לחכות", "sub": "…", "room": "amirot-haste",
      "creations": [ { "id": "1", "style": "poster", "title": "…", "text": "…", "image": "art/haste-a.jpg" } ] }
  ]
}
```
**נתיבים ושדות:**
- נתיב תמונה יחסי מתפרש ביחס לקובץ ה-JSON.
- `room` הוא ה-slug של החדר ב-TAARUCHA. כשהוא קיים, הכפתור "כניסה לחדר" פעיל.
- `palette` הוא מפתחות ה-DNA של האפליקציה:
  - `a`, `b`, `c`, `s`: צבעים.
  - `accent`: צבע הדגשה.
  - `marker`: צבע המרקר.
  - `paper` ו-`paper2`: צבעי הרקע.
  - `ink`: צבע הטקסט.
  - `b-wash` ו-`s-wash`: גוונים בהירים לרקע.

## כללי תוכן (רמה 999)
- **שלושה שלבים:**
  - **ידע:** עובדה עם מקור.
  - **הבנה:** מנגנון, השוואה או "ממה למה".
  - **יישום:** מה עושים מחר בבוקר, ודוגמה מהעיר.
- **כמה חדרים:** 6 לפחות לכל אפליקציה, ולפחות אחד מכל שלב.
- **כמה יצירות:** בכל חדר 4 עד 6 יצירות, בעיצובים שונים. אף עיצוב לא חוזר באותו חדר.
- **כמה כותרת:** כותרת עד 8 מילים. הסבר עד 20 מילים. מאמר: 3 עד 5 פסקאות קצרות.
- **מקורות:** רק עובדות שכבר נמצאות בנתונים של האפליקציה. לא ממציאים, ולכל ציטוט יש מקור.
- **תמונות:** רק תמונות שכבר יש לאפליקציה רישיון עליהן. כשאין תמונה, בוחרים עיצוב בלי תמונה.

## ייצוא לתמונות ולתערוכה
1. `node <AppOfApp-GH>/tools/creations-render.cjs "http://localhost:4173/#/creations" public/creations.json public/creations` מייצא PNG בגודל 1240×1754 לכל יצירה, ורושם את הנתיב בשדה `png`.
2. **TAARUCHA, מהממשק:** הכפתור "העלאה לחדר בתערוכה" פותח את `https://taarucha.vercel.app/studio/import?src=<json>&topic=<id>`.
   - אחרי כניסה, נוצרת תערוכה (חדר) לנושא, עם ה-slug `<app.id>-<topic.id>`.
   - כל יצירה נתלית על הקיר כעבודת דימוי, עם הטקסט שלה בגוף העבודה.
3. **TAARUCHA, מ-SQL (מתוך שיחת Claude):**
   - הכנסה לטבלאות `taarucha_exhibitions` ו-`taarucha_works`, לפי אותו מיפוי.
   - התמונות מוגשות דרך `https://cdn.jsdelivr.net/gh/<repo>@<commit>/public/...`, ולכן לא תלויות במכסת Vercel.
