# רחובות אשדוד: שכבה משותפת לכל האפליקציות העירוניות

==כתובת הופכת לרחוב ולרובע, בלי שירות חיצוני.==
מקור אחד לרחובות העיר, מוגש מתיק האפליקציות כמו `ai-menu.js`. כל אפליקציה עירונית משתמשת בו, ולא מחזיקה עותק משלה.

## המקור

- עיריית אשדוד, קובץ `rehevot.shp`, שנשלח על ידי ענת ב-03.11.2026. רשת ישראל החדשה (Israel TM Grid).
- **2,991** קטעי רחוב, **1,228** שמות ו-**40** ערכי רובע.
- הקובץ המקורי נשמר ב-SHIMUR-GH, בתיקייה `data/gis/rehovot/`, עם סקריפט ההמרה.
- כאן הוא מוגש ב-WGS84: `public/gis/ashdod-streets.geojson`. השדות הם name, quarter, tier (מידרג), code (קוד רחוב) ו-year.

## שימוש

```html
<script src="https://anat1969.github.io/AppOfApp-GH/streets.js"></script>
```

GitHub Pages קודם, ו-Vercel (`https://appofapp-gh.vercel.app/streets.js`) כגיבוי, כמו `walk.js`.

```js
await AIStreets.nearest(lat, lng);      // { name, quarter, tier, code, metres } או null, עד 60 מ'
await AIStreets.locate('שד הרצל 12');  // { lat, lng, name, quarter, approx: 'street' } או null
await AIStreets.load();                 // GeoJSON, לשכבה במפה
```

- `locate` מוצא את הרחוב ולא את הבית: הנקודה היא מרכז קטעי הרחוב. כשמשתמשים בה, מסמנים "מיקום לפי הרחוב".
- ברחוב שעובר בכמה רובעים, רובע שכתוב בכתובת קובע. בלי רובע, מוחזר הרובע של רוב הקטעים.
- חניונים (שמות שמתחילים ב"חני") לא נחשבים רחוב.

## מה לא מוצג

השדות `סוג_ר`, `אופי_` ו-`executing` אינם מוגדרים בקובץ, ולכן לא הועברו. כשענת תסביר אותם, הם ייכנסו לכאן.

## שימושים

- שימור אשדוד (SHIMUR-GH): שכבה במפה, ושם הרחוב והרובע של כל ממצא מהשטח. עותק מקומי מאותו מקור.
- שילוט באתרי בנייה (SignAshdod-GH): רובע לכל אתר, ומיקום לפי הרחוב כשאין התאמה לכתובת המלאה.
